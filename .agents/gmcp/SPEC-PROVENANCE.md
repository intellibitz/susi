# Pinned MCP specification text

`.agents/gmcp/spec` holds third-party Model Context Protocol specification
text, vendored verbatim at the upstream commits below. Susi core keeps it as a
public, read-only reference. The GMCP certification that pins and checks it (the
requirements ledger, the per-file pins, fixtures, contracts, roadmap and
evidence) is maintained in Susi Commercial Apps, which reads this directory from
a core checkout.

Each file keeps the license of its upstream repository at the pinned commit.
The `LICENSE` of modelcontextprotocol/modelcontextprotocol at `86f6e0c6` states
that new specification contributions are Apache-2.0, contributions not yet
relicensed remain MIT, and documentation (excluding specifications) is
CC-BY-4.0. The other upstreams carry their own `LICENSE` at their pinned
commit.
